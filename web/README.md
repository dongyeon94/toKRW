# toKRW (웹)

브라우저에서 도는 같은 앱. 아이폰 홈 화면에 추가하면 아이콘이 생기고 전체 화면으로 뜹니다.
서명이 없으니 만료도 없습니다. 안드로이드 폰에서도 그대로 열립니다.

## 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면, 계산, 환율 조회까지 전부 들어 있는 단일 파일 |
| `manifest.webmanifest` | 홈 화면에 추가했을 때의 이름, 아이콘, 전체 화면 설정 |
| `sw.js` | 페이지를 캐시해서 오프라인에서도 열리게 하는 서비스 워커 |
| `icons/` | 홈 화면 아이콘 |

네이티브 앱 두 개와 같은 통화 목록, 같은 환율 공급처, 같은 계산 방식을 씁니다.
환율과 마지막에 고른 통화는 브라우저 저장소에 남습니다.

## 계산기

키패드 오른쪽 열이 연산자입니다. 더하기, 빼기, 곱하기, 나누기와 퍼센트를 씁니다.
계산하는 동안 위쪽에 식이 뜨고, 아래 원화 금액은 지금 값 기준으로 계속 바뀝니다.

**퍼센트를 누르면 걸려 있던 계산까지 바로 끝납니다.** 등호를 따로 누르지 않아도 됩니다.
할인가를 보려는데 깎이는 금액이 떠서 헷갈리는 일을 없앤 것입니다.

| 누른 것 | 결과 | 쓰임새 |
| --- | --- | --- |
| `10000 − 20 %` | 8000 | 20% 깎아줬을 때 낼 금액 |
| `100 + 15 %` | 115 | 팁이나 봉사료를 얹은 금액 |
| `200 × 10 %` | 20 | 200 의 10% 가 얼마인지 |
| `50 %` | 0.5 | 그냥 100 으로 나누기 |

더하기와 빼기는 왼쪽 값의 몇 퍼센트로 읽고, 곱하기와 나누기는 그냥 100 으로 나눕니다.
무엇을 계산했는지는 금액 위 식 줄에 `10,000 − 20%` 처럼 남습니다.
이어서 `+ 500 =` 을 누르면 할인가에 배송비를 더할 수도 있습니다.

`C` 는 전부 지우고 `⌫` 는 한 자만 지웁니다. 계산으로 나온 값에서 `⌫` 를 누르면 통째로 지워집니다.
`00` 은 동이나 루피아처럼 자릿수가 큰 통화를 찍을 때 씁니다.
0 으로 나누면 식 자리에 안내가 뜨고 `C` 를 누르면 풀립니다.

맥이나 아이패드에서 물리 키보드로도 됩니다. 숫자와 `+ - * /` `%` `=` `Enter` `Backspace` `Esc` 를 받습니다.

## 통화 목록 정리

52개를 매번 훑기 번거로우니 두 가지를 넣었습니다.

**즐겨찾기.** 각 줄 오른쪽 별표를 누르면 맨 위 "자주 쓰는 통화" 칸으로 올라갑니다.
처음에는 달러, 엔, 위안, 동, 루피아가 올라가 있고 마음대로 바꾸면 됩니다.

**숨기기.** 검색창 옆 편집을 누르면 각 줄에 체크박스가 생깁니다.
체크를 끄면 목록에서 빠집니다. 다시 편집으로 들어가면 되돌릴 수 있습니다.

기본으로는 아래 11개만 보이고 나머지 41개는 빠져 있습니다.
동남아와 동아시아 여행에서 주로 쓰는 통화들입니다.

| 나라 | 통화 |
| --- | --- |
| 미국, 괌 | USD |
| 일본 | JPY |
| 중국 | CNY |
| 홍콩 | HKD |
| 대만 | TWD |
| 싱가포르 | SGD |
| 태국 | THB |
| 베트남 | VND |
| 필리핀 | PHP |
| 인도네시아 | IDR |
| 말레이시아 | MYR |

괌은 미국 달러를 쓰므로 USD 하나로 덮입니다.

숨긴 통화도 검색하면 그대로 나옵니다. 영영 못 쓰게 되는 게 아니라 평소 목록만 짧아집니다.
별표를 누르면 숨김이 자동으로 풀리고, 숨기면 별표가 풀립니다. 둘이 동시에 켜지지 않습니다.

선택한 내용은 브라우저에 저장돼서 다음에 열어도 그대로입니다.
기기마다 따로 저장되고 다른 사람에게는 보이지 않습니다.

기본 목록을 바꿀 때는 `index.html` 의 `DEFAULT_VISIBLE` 과 `DEFAULT_FAVORITES` 를 고치고
바로 아래 `PRESET_VERSION` 값도 같이 바꿉니다.
그래야 이미 저장된 기기에서도 새 목록이 한 번 덮어써집니다. 안 바꾸면 예전 설정이 그대로 남습니다.

## 아이폰 홈 화면에 추가하기

1. 사파리로 주소를 엽니다. 크롬이 아니라 **사파리여야** 합니다.
2. 아래 공유 버튼을 누릅니다.
3. **홈 화면에 추가** 를 고릅니다.

추가된 아이콘으로 열면 주소창 없이 앱처럼 뜹니다.

## 집에서 잠깐 확인만 할 때

맥에서 이 폴더를 그대로 띄우고 같은 와이파이의 폰으로 접속하면 됩니다.

```bash
cd web
python3 -m http.server 8765 --bind 0.0.0.0
```

맥의 주소는 `ipconfig getifaddr en0` 으로 확인합니다.
다만 맥이 켜져 있어야 하고, `http` 라서 오프라인 캐시는 동작하지 않습니다.
계속 쓰려면 아래처럼 어딘가에 올려 두는 편이 낫습니다.

## 계속 쓰려면

정적 파일 네 종류가 전부라 아무 정적 호스팅에나 올라갑니다. 빌드 과정도 없습니다.
GitHub Pages, Cloudflare Pages, Netlify 같은 곳의 무료 요금제로 충분합니다.
