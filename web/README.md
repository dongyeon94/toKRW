# toKRW (웹)

브라우저에서 도는 같은 앱. 아이폰 홈 화면에 추가하면 아이콘이 생기고 전체 화면으로 뜹니다.
서명이 없으니 만료도 없습니다. 안드로이드 폰에서도 그대로 열립니다.

## 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면, 계산, 환율 조회까지 전부 들어 있는 단일 파일 |
| `manifest.webmanifest` | 홈 화면에 추가했을 때의 이름, 아이콘, 전체 화면 설정 |
| `sw.js` | 페이지를 캐시해서 오프라인에서도 열리게 하는 서비스 워커 |
| `icons/` | 홈 화면 아이콘 |

네이티브 앱 두 개와 같은 통화 목록, 같은 환율 공급처, 같은 계산 방식을 씁니다.
환율과 마지막에 고른 통화는 브라우저 저장소에 남습니다.

## 통화 목록 정리

52개를 매번 훑기 번거로우니 두 가지를 넣었습니다.

**즐겨찾기.** 각 줄 오른쪽 별표를 누르면 맨 위 "자주 쓰는 통화" 칸으로 올라갑니다.
처음에는 달러, 엔, 유로, 위안, 동, 루피아가 올라가 있고 마음대로 바꾸면 됩니다.

**숨기기.** 검색창 옆 편집을 누르면 각 줄에 체크박스가 생깁니다.
체크를 끄면 목록에서 빠집니다. 다시 편집으로 들어가면 되돌릴 수 있습니다.

숨긴 통화도 검색하면 그대로 나옵니다. 영영 못 쓰게 되는 게 아니라 평소 목록만 짧아집니다.
별표를 누르면 숨김이 자동으로 풀리고, 숨기면 별표가 풀립니다. 둘이 동시에 켜지지 않습니다.

선택한 내용은 브라우저에 저장돼서 다음에 열어도 그대로입니다.

## 아이폰 홈 화면에 추가하기

1. 사파리로 주소를 엽니다. 크롬이 아니라 **사파리여야** 합니다.
2. 아래 공유 버튼을 누릅니다.
3. **홈 화면에 추가** 를 고릅니다.

추가된 아이콘으로 열면 주소창 없이 앱처럼 뜹니다.

## 집에서 잠깐 확인만 할 때

맥에서 이 폴더를 그대로 띄우고 같은 와이파이의 폰으로 접속하면 됩니다.

```bash
cd web
python3 -m http.server 8765 --bind 0.0.0.0
```

맥의 주소는 `ipconfig getifaddr en0` 으로 확인합니다.
다만 맥이 켜져 있어야 하고, `http` 라서 오프라인 캐시는 동작하지 않습니다.

## 계속 쓰려면

정적 파일 네 종류가 전부라 아무 정적 호스팅에나 올라갑니다. 빌드 과정도 없습니다.
