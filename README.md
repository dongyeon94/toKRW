# toKRW

통화를 고르고 키패드로 금액을 누르면 실시간 환율로 원화 금액을 바로 보여 주는 테스트 앱.
안드로이드와 iOS 두 벌을 따로 만들었고, 화면 구성과 계산 방식은 같습니다.

```
android/   Kotlin + Jetpack Compose
ios/       Swift + SwiftUI
web/       HTML + 자바스크립트, 깃허브 페이지로 배포
scripts/   환율을 파일로 굽는 스크립트
```

웹 버전은 https://dongyeon94.github.io/toKRW/ 에서 열립니다.
아이폰 사파리로 열고 공유 버튼에서 홈 화면에 추가하면 아이콘이 생깁니다.
서명이 없으니 만료도 없고, 안드로이드 폰에서도 그대로 열립니다.

## 동작 방식

두 앱 모두 USD 기준 환율 표를 한 번만 받아 두고, 고른 통화의 원화 값을 교차 계산합니다.
그래서 통화를 바꿔도 네트워크를 다시 타지 않고 즉시 결과가 바뀝니다.

환율은 키가 필요 없는 무료 공개 API 두 곳에서 가져오고, 앞쪽이 실패하면 뒤쪽으로 넘어갑니다.

| 순서 | 공급처 | 주소 |
| --- | --- | --- |
| 1 | open.er-api.com | `https://open.er-api.com/v6/latest/USD` |
| 2 | frankfurter.dev | `https://api.frankfurter.dev/v1/latest?base=USD` |

받아 온 표는 기기에 저장해 두었다가 앱을 켤 때 바로 보여 주고, 하루가 지났으면 새로 받습니다.
공급처가 하루에 한 번 값을 올리기 때문입니다. 그 사이에 새로 받고 싶으면 오른쪽 위 새로고침 버튼을 누르면 됩니다.
비행기 모드처럼 네트워크가 없을 때도 마지막 값으로 계산이 됩니다.

## 화면

- 왼쪽 위 칩을 누르면 통화 목록이 열립니다. 코드나 한글 이름으로 검색할 수 있고, 목록에 현재 환율이 함께 보입니다.
- 웹 버전은 목록을 정리할 수 있습니다. 별표로 자주 쓰는 통화를 위에 고정하고, 편집으로 안 쓰는 통화를 목록에서 뺍니다.
- 아래 키패드로 금액을 누르면 원화 금액이 실시간으로 바뀝니다.
- 지우기 키를 길게 누르면 전체가 지워집니다.
- 엔이나 동처럼 1단위 값이 작은 통화는 국내 은행 고시처럼 100단위 환율로 표시합니다.

## 매일 갱신

깃허브 액션이 한국시간 매일 오전 9시 30분에 환율을 받아 `web/rates.json` 에 커밋하고,
그 상태로 깃허브 페이지에 배포합니다. 공급처가 00시 UTC 즈음 값을 올린 뒤라 갓 나온 값을 받습니다.

웹 앱은 공개 API 를 먼저 부르고, 둘 다 실패하면 이 파일로 넘어갑니다.
그래서 API 가 막히거나 폰이 오프라인이어도 하루 이내의 값으로 계산됩니다.

손으로 돌리려면 저장소의 Actions 탭에서 "환율 갱신 후 배포" 를 골라 Run workflow 를 누르면 됩니다.

## 참고

환율은 시장 중간값입니다. 은행 매매기준율이나 카드사 청구 환율과는 차이가 납니다.
